# 🎁 QueroEsse • Plataforma Inteligente de Listas de Presentes

**QueroEsse** é uma aplicação moderna para criação de listas de presentes para qualquer tipo de celebração (**Casamento, Aniversário, Chá de Bebê, Casa Nova / Open House e Geral**).

---

## ✨ Principais Diferenciais Criados

1. **Templates e Visuais por Nicho:**
   - 💍 **Casamento:** Estética romântica, tons champagne/rosé e tipografia sofisticada.
   - 🎂 **Aniversário / 30tei:** Visual alegre, festivo e vibrante.
   - 🍼 **Chá de Bebê / Chá Rifa:** Tons pastéis delicados e acolhedores.
   - 🏡 **Casa Nova / Open House:** Estilo contemporâneo e aconchegante.
   - ✨ **Geral:** Neutro e versátil para formaturas, amigos secretos ou festas.

2. **Identificação Flexível dos Convidados:**
   - **Modo Lista Fechada (Pré-cadastrada):** O anfitrião pode colar uma lista (ex: 40 convidados) de uma só vez. Quando o convidado abre o link, aparece uma barra elegante no topo: *"Quem está acessando a lista?"*, e a pessoa escolhe o próprio nome com busca rápida!
   - **Modo Aberto:** Qualquer convidado pode abrir o link e apenas digitar seu nome ao reservar.

3. **Bloqueio Automático em Tempo Real:**
   - O item reservado é imediatamente bloqueado para novos convidados, exibindo *"Reservado por [Nome do Convidado]"* e evitando presentes repetidos.
   - **Suporte a Múltiplas Unidades / Cotas:** Permite cadastrar ex: 3 jogos de toalhas ou 5 cotas de chopp/lua de mel. O sistema exibe *"X de Y disponíveis"* e só bloqueia ao esgotar.

4. **Campos Opcionais Completos:**
   - Valor sugerido/estimado (R$).
   - Link de onde encontrar (Amazon, Magazine Luiza, Mercado Livre, etc.) com botão direto de compra.
   - Mensagem de carinho e telefone para contato.

5. **Painel do Anfitrião Completo:**
   - Métricas em tempo real (Presentes cadastrados, reservados, % concluído e valor total estimado).
   - Gestão de itens e cancelamento de reservas caso alguém precise mudar.
   - Mural de Recados com todas as mensagens dos convidados.
   - Botão para compartilhar no WhatsApp com mensagem preformatada e QR Code pronto para convite impresso.

## 🚀 Como Iniciar

1. Abra o terminal na pasta:
   ```bash
   cd E:\MINHAS_PROGRAMAÇÕES\queroesse
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Acesse no navegador:
   👉 **http://localhost:3000**
